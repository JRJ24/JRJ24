## 👨‍💻 Un poco sobre mí

Soy desarrollador de software con enfoque **Full Stack**, especializado en construir soluciones para operaciones empresariales, logística, transporte y automatización.

Disfruto transformar necesidades reales en productos que conectan personas, procesos y datos. Mi trabajo abarca el ciclo completo: **entender el problema, diseñar la solución, implementar frontend y backend, modelar la base de datos y preparar su despliegue**.

Me motiva seguir aprendiendo, colaborar con otros desarrolladores y encontrar maneras más simples y sólidas de resolver problemas difíciles.

## 🎯 Lo que puedo aportar

- **Aplicaciones web y móviles:** interfaces responsivas, paneles administrativos y experiencias basadas en roles.
- **Backend y arquitectura:** APIs REST, autenticación, lógica de negocio, integraciones y organización modular.
- **Datos y automatización:** diseño de modelos de datos, consultas, reportes y optimización de flujos operativos.
- **DevOps y despliegue:** contenerización, servidores Linux, proxies inversos y publicación de aplicaciones.

## 🚀 Proyectos destacados

### 🚚 RUTA RD — Ecosistema de transporte

Desarrollo de una solución de transporte con **API modular, portal operativo y aplicación móvil para conductores**. El proyecto contempla gestión de órdenes, asignaciones, rutas, seguimiento GPS, autenticación, notificaciones y flujos de entrega.

**Tecnologías:** NestJS, TypeScript, PostgreSQL, Prisma, React Native, Expo y Socket.IO.

[Explorar API](https://github.com/JRJ24/transport-api) · [App de conductores](https://github.com/JRJ24/transport-driver) · [Portal de operaciones](https://github.com/JRJ24/transport-portal)

### 📦 Seguimiento operativo de envíos — Importadex / MIREX

**Prototipo funcional** para visualizar y organizar solicitudes de envío: panel operativo, filtros, historial, información de seguimiento y reportes. Un ejemplo de cómo convertir procesos con múltiples datos en una interfaz útil para la operación.

**Tecnologías:** React, JavaScript y visualización de datos.

[Explorar repositorio](https://github.com/JRJ24/web-based-tracking-system-Importadex)

### ⚙️ Flypack Automatize — Automatización de operaciones

Cliente web orientado a la automatización y gestión de procesos logísticos, con una interfaz pensada para facilitar tareas operativas y el acceso a información.

**Tecnologías:** React, TypeScript y Vite.

[Explorar repositorio](https://github.com/JRJ24/flypackAutomatizeClient)

### 📈 Predicción de precios — Modelos y análisis

Proyecto que explora enfoques de predicción y análisis de precios mediante **regresión lineal, media móvil simple y ROC Momentum**.

**Tecnología:** C#.

[Explorar repositorio](https://github.com/JRJ24/PrediccionPrices)

## 🧠 Mi manera de construir software

Creo que el código es un medio, no el fin. Primero busco entender **qué problema debe resolverse**; después elijo una arquitectura adecuada, priorizo la claridad de la implementación y pienso en cómo mantener y evolucionar la solución.

Me interesan especialmente los desafíos de **sistemas empresariales, integraciones, automatización, backend, bases de datos e infraestructura**.
